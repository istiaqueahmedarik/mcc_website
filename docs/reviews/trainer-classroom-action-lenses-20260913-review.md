# Trainer classroom animated icons and grouped action lenses

The trainer classroom now uses locally bundled heroicons-animated artwork and animation for its main classroom controls, arrival/live toolbar, Updates feed and contest workspace. Grouped action rows—including Refresh / Generate report / Share—share the dock's glass shader instead of retaining individual hover surfaces.

## Review flow
1. `client/src/components/TrainerVisualContext.jsx` enables the presentation only inside the trainer classroom. `ui/heroicons-animated/TrainerClassroomIcons.jsx` maps existing icon names to upstream components while retaining the original student rendering and busy spinners. Explicit imports avoid pulling in the entire Lucide catalogue. The 62 upstream files under `ui/heroicons-animated/classroom/` retain MIT provenance; adaptations use the existing Framer Motion dependency and inline span wrappers. Animations start from the parent control's pointer entry, never from keyboard focus, and honor reduced motion.
2. `client/src/app/classroom/live/[id]/TrainerActionGroup.jsx` preserves action children and supplies the shared in-flow shell. Shader canvases mount only during hover/focus and dispose after exit. `TrainerActionGroup.module.css` supplies wrapping, 44px minimum targets, focus outlines, semantic primary/destructive colors and transparent hover surfaces. Scoped selectors neutralize old hover backgrounds, shadows and movement without changing student buttons.
3. `TrainerDockLens.jsx` reuses the same shader for the existing dock and action groups. Optional item selectors support wrapped-row vertical positioning; action lenses hide when idle. A consistent monotonic clock and nonnegative timestep prevent the unstable spring positions observed during preview testing. Existing context-loss, contrast/transparency, resize and disposal paths remain.
4. Integrations replace 30 button-row wrappers across `ClassroomLiveClient.js`, `TrainerClassroomInterior.jsx`, `ClassroomContestPanel.jsx` and `UpdatesTab.js`. Native buttons, links, dialog triggers, disabled/busy conditions and handlers are retained. No API, scoring, provider session, database or authorization changes.
5. `ui/animated-collapsible.jsx` gives contest sources, classroom details, and the six existing section cards the requested shadcn-animated height, fade, and vertical transition. Existing buttons remain the accessible disclosure controls with `aria-expanded`/`aria-controls`; reduced-motion users get an immediate state change. Grouped action CSS removes the inherited dock shell shadow, active shadow, inset rim highlight, and hover-lens drop shadow while keeping the 28px border above the shader.

## Evidence and boundaries
- Full client lint: zero errors, nine existing unrelated warnings. Focused final lint checked the changed animation components.
- Production build completed successfully after the focus/import refinements. Final CSS precedence and preview refinements were subsequently compiled by the development server and verified in the browser.
- Browser fixture: `/trainer/dock-lens-prototype/actions` renders sample actions with no real data. Verified Generate report/Share/Schedule callbacks, a 240px wrapped group, 390px viewport with no horizontal overflow, 44px targets, stable second-row lens geometry, visible keyboard focus, disabled-button Tab skip, and canvas disposal after leaving a group.
- The preview also includes the real classroom radius scope and a legacy rounded-lg wrapper: computed glass-shell radius is 28px and button radius is 16px, confirming the new shell wins over the prior radius rules.
- The action shell uses a permanent, pointer-transparent `::after` rim with inherited 28px corners. It remains above the shader when `data-webgl` switches between fallback, loading, and active, so the rounded boundary does not disappear during lens activation.
- After the shadow-removal follow-up, computed action-group styles are `box-shadow: none` in both fallback and active WebGL states. The rim stays 1px with 28px corners and no inset shadow; all active decorative lens/canvas layers also compute to no shadow.
- The isolated Contest sources fixture confirms the disclosure content is present during exit, moves from about 10px to rest while opening, settles at full height and opacity, and unmounts after closing. Its trigger changes `aria-expanded` with the content lifecycle.
- Computed hovered-button styles: transparent background, no box-shadow, no transform. Stable second-row lens: top approximately 49px, height 52px after expansion. No browser errors observed.
- Available browser is signed out. These checks do not establish authenticated classroom, production or real-account QA. Reduced-motion and contrast/transparency paths were reviewed in source; their runtime emulation was not performed.

Rollback: restore the four integration imports/wrappers and provider, remove new action/icon modules and the isolated preview, and revert only the added optional lens geometry/clock changes. Preserve pre-existing dock, font and radius work.
